## 一、核心游戏循环

游戏核心循环由六个环节组成，每次完整循环代表诗人生命中一段旅程（数天至数月）。循环速度由玩家掌控，一个循环可在 5–30 分钟内完成，不存在强制等待。

| 步骤 | 环节 | 玩家行为 | 系统响应 |
|------|------|---------|---------|
| ① | 做出选择 | 在地图或对话中选择前进方向 / 回应来信 | 路线解锁，触发事件，情绪值变化 |
| ② | 游历地图 | 点击目标地点，触发途中事件卡 | 事件卡展示，情绪更新，时间推进 |
| ③ | 情绪积累 | 通过连续事件使情绪值达到诗词触发阈值 | 情绪条实时渲染，触发条件持续检测 |
| ④ | 诗词触发 | 在特定地点满足情绪条件 | 进入水墨沉浸场景，旁白渲染情境 |
| ⑤ | 拼词创作 | 选择正确词语逐行完成诗词 | 即时反馈、错选教学、完成后全诗展示 |
| ⑥ | 揭秘收藏 | 诗词进入典藏，展示历史背景 | 典藏更新，关系值变化，下一事件解锁 |

> **设计原则**：循环结束后玩家自然回到地图，进入下一段旅程。整体节奏由玩家掌控，不设强制付费墙或等待门槛。

## 二、系统设计规格

### 2.1 情绪驱动系统（Mood System）

#### 数据结构

```typescript
interface MoodState {
  passion:      number;  // 豪情：进取、豪迈  (0–100)
  sorrow:       number;  // 忧思：悲悯、忧郁  (0–100)
  freedom:      number;  // 洒脱：自在、超然  (0–100)
  anger:        number;  // 愤懑：不平、愤怒  (0–100)
  homesickness: number;  // 乡愁：思乡、怀旧  (0–100)
}
```

#### 情绪变化来源

| 来源类型 | 触发方式 | 典型变化幅度 |
|---------|---------|------------|
| 事件卡（Event） | 到达地点或时间推进触发 | 固定值，见各事件 `mood_delta` 配置 |
| 地点属性（Location） | 玩家到达地点时自动触发 | 小幅微调（±5~15） |
| 唱和互动（Exchange） | 诗词往来的选项结果 | 由玩家选项决定（见 2.3） |
| 时间自然衰减 | 每推进一个游戏月 | 各维度向 50 靠近，每月 ±2 |
| 季节 / 天气 | 系统按月份或事件触发 | 随机微调（±3~8） |
| 时代洪流（Crisis） | 历史大事件爆发时 | 大幅强制变化（见 2.5） |

#### 诗词触发条件结构

```typescript
interface TriggerCondition {
  location_id:    string;
  mood: {
    passion?:      { min?: number; max?: number };
    sorrow?:       { min?: number; max?: number };
    freedom?:      { min?: number; max?: number };
    anger?:        { min?: number; max?: number };
    homesickness?: { min?: number; max?: number };
  };
  year_range?:    [number, number];  // 可触发年份范围
  time_of_day?:   'day' | 'night' | 'any';
  requires_event?: string;           // 前置事件 ID（可选）
}
```

### 2.2 诗词拼组系统（Poem Assembly）

#### 触发流程（共 7 步）

1. 触发条件满足 → 地图出现金色涟漪动效提示
2. 玩家点击确认 → 淡入过渡动画 → 进入创作场景界面
3. 背景展示当前地点水墨场景，旁白描述诗人当下心境（1–2 句）
4. 逐行展示诗词，有填空行时展示选项组件（A/B/C/D）
5. 玩家选择 → 即时反馈（正确：绿色确认；错误：红色 + 针对该选项的教学说明）
6. 全部完成 → 书法体全诗展示 + 背景故事 + 现代白话译文
7. 诗词加入典藏，时间轴节点变为实心星形，返回地图

#### 选项设计规则

| 规则项 | 说明 |
|--------|------|
| 选项数量 | 每题 4 个选项（A/B/C/D），正确答案随机分配在 A–D 中 |
| 干扰项策略 | 形近字 / 同义词 / 押韵字 / 语义相反词（混合使用） |
| 错误反馈粒度 | 每个干扰项单独撰写说明（音 / 形 / 意层面） |
| 跳过机制 | 3 次错误后可选"跳过并看答案"，典藏中标注未满分 |
| 评分规则 | 一次正确=100%；二次=75%；三次及以上=50%；完成即解锁 |
| 无阻断设计 | 拼组失败不阻断游戏进程，仅影响典藏分数标注 |

### 2.3 唱和交流系统（Poetic Exchange）

#### 触发条件（需同时满足）

- 与目标诗人的 `relationship_strength` ≥ 20
- 当前游戏年份 ≥ 该关系的 `established_year`
- 本次往来在 `exchanges` 数据中存在且未触发过
- 距上次往来 ≥ 15 天游戏时间（防止频繁触发）

#### 关系值等级

| 关系值范围 | 关系状态 | 解锁内容 |
|-----------|---------|---------|
| 0–20 | 相识 | 基础往来对话 |
| 21–50 | 一般朋友 | 可唱和，解锁部分历史记录 |
| 51–80 | 深交 | 高质量唱和，解锁隐藏诗词路线 |
| 81–100 | 挚友 / 知己 | 解锁最终联合场景与结局内容 |

**衰减规则**：每 15 游戏天未发生互动，`relationship_strength` −1（下限 0）。

---

### 2.4 人生岔路系统（Life Choice）

#### 设计原则

- 每个岔路 2–3 个选项，至少 1 个对应历史真实走向（`is_historical: true`）
- 选项代价清晰：情绪变化 + 解锁内容差异在选项卡上显示
- 非历史路径解锁的诗词在典藏中标注「平行历史」
- 任意选项完成后，展示"历史上真实发生了什么"（教育收尾，不评判选择）

#### 数据结构

```typescript
interface LifeChoice {
  id:                 string;
  event_id:           string;
  prompt:             string;        // 情境描述（展示给玩家）
  historical_context: string;        // 历史补充说明
  options: Array<{
    id:                string;
    text:              string;
    mood_delta:        Partial<MoodState>;
    unlocks_poems:     string[];
    unlocks_locations: string[];
    next_event_id:     string;
    is_historical:     boolean;
    historical_note:   string;       // 选后展示
  }>;
}
```

### 2.5 时代洪流系统（Historical Crisis）

时代洪流按历史年份自动触发，不可跳过。触发时全屏展示事件动画，地图状态同步更新，所有活跃诗人情绪值强制变化。

#### MVP 预设事件表

| 年份 | 事件名称 | 地图影响 | 情绪强制变化 |
|------|---------|---------|------------|
| 755 年 | 安史之乱爆发 | 长安标红，北方路线关闭 | 愤懑+35，乡愁+40 |
| 757 年 | 唐军收复两京 | 北方路线部分恢复 | 豪情+15，愤懑−20 |
| 762 年 | 玄宗 / 肃宗相继驾崩 | 无地图变化 | 忧思+25，乡愁+15 |
| 763 年 | 安史之乱平定 | 北方路线完全恢复 | 豪情+20，忧思−15 |

### 2.6 典藏与成就系统（Collection）

#### 典藏内容类型

| 典藏类型 | 触发来源 | 展示内容 |
|---------|---------|---------|
| 诗词典藏 | 拼组完成 | 全文、注释、白话译文、背景故事、情境插图 |
| 历史场景 | 人生岔路完成 | 玩家选择结果 + 历史真实走向对比 |
| 关系记录 | 唱和往来 | 双方交流记录、互赠诗词、关系发展历程 |
| 地点印记 | 到达地点 | 地点简介、历史沿革、与该诗人的关联 |
| 成就 | 特定条件达成 | 称号图标 + 解锁内容（隐藏场景等） |

#### 李白主线成就设计（示例）

| 成就名称 | 触发条件 | 奖励内容 |
|---------|---------|---------|
| 诗仙启程 | 触发第 1 首诗词 | 李白人物卡 + 生平简介解锁 |
| 游历千山 | 到达全部 10 个地点 | 隐藏地点「天门山」解锁 |
| 知己难求 | 李白–杜甫关系值 ≥ 80 | 李杜相遇特别纪念场景 |
| 诗仙归去 | 解锁全部 10 首诗词 | 「诗仙传说」结局动画 |

## 三、地图与时间轴设计

### 3.1 地图系统

#### 渲染层次（从底到顶）

- **底层（静态）**：水墨风格 SVG 矢量地图，唐 / 宋朝代切换时替换整张底图
- **数据层**：GeoJSON 地点标注，含坐标、类型、历史名称、连接关系
- **路线层**：诗人游历路线动态绘制；实线=已走，虚线=可达，灰色=未解锁
- **事件层**：可点击标记覆盖在地点上；时代洪流触发时叠加全屏动效

#### 地点类型定义

| 类型 ID | 中文名 | 地图图标 | 说明 |
|--------|-------|---------|------|
| `city` | 城市 | 印章红点（大） | 历史主要城市，政治与文化中心 |
| `landmark` | 名胜 | 水墨山形图标 | 山岳、湖泊、名楼等自然名胜 |
| `pass` | 关隘 | 城墙图标（深灰） | 重要交通要道与军事关口 |
| `palace` | 宫殿 | 宫殿图标（金色） | 皇家建筑与官署 |
| `hidden` | 隐藏地点 | 问号图标（灰） | 成就或特定条件解锁后显示 |

### 3.2 时间轴系统

#### 布局规格

- **位置**：主界面底部固定区域，高度 80px，横向展开
- **展示范围**：当前诗人完整生命周期，可水平拖拽滚动
- **时间密度**：每 10 年约 60px；事件标记直径 12px
- **当前时间**：滑动指针，随游戏进行自动右移

#### 事件标记类型

| 标记类型 | 颜色 | 形状 | 交互行为 |
|---------|------|------|---------|
| 个人事件（`personal`） | `#2E75B6` 深蓝 | 圆形 | 点击展示事件简介弹窗 |
| 时代大事（`crisis`） | `#C0392B` 警示红 | 三角形 | 点击展示历史事件说明 |
| 诗词节点（已触发） | `#D4A017` 金色 | 星形（实心） | 点击进入诗词回放模式 |
| 诗词节点（未触发） | `#D4A017` 金色 | 星形（空心） | 悬浮显示触发提示，激励探索 |
| 人生岔路（`choice`） | `#7B6DBF` 紫色 | 菱形 | 点击展示已选路径记录 |

## 五、技术选型

| 层次 | 技术方案 | 选型理由 |
|------|---------|---------|
| 游戏引擎 | Phaser.js 3.x | 成熟 2D Web 引擎，场景 / 动画 / 事件系统完善，文档丰富 |
| 关系图谱 | D3.js | 力导向图算法成熟，支持高度自定义视觉样式 |
| 地图底图 | 自定义 SVG（水墨矢量） | 矢量无损缩放，风格完全可控，朝代切换替换文件即可 |
| 类型系统 | TypeScript | 数据结构复杂，类型安全减少运行时 Bug |
| 构建工具 | Vite | 热重载快，与 Phaser 兼容性良好，零配置启动 |
| UI 样式 | CSS Modules | 游戏场景用 Phaser 渲染；UI 组件用 CSS 模块化隔离 |
| 数据 | JSON 静态资产 + LocalStorage | 内容静态加载，进度本地存储，MVP 阶段无需后端 |
| 音效（P2） | Howler.js | 轻量音频库，Web Audio API 封装，支持空间音效 |

## 七、美术与 UI 设计规格

### 7.1 整体视觉风格：“新东方·春生”（Neo-Oriental Spring）

跳出传统“泛黄陈旧水墨”的刻板印象，拥抱**当代极简、春日生机与通透现代美学**，同时将唐宋器物弧线融入现代组件：

- **现代与生机**：以春水碧（#10B981）、晨露冷白（#F6F9F5）与青瓷秘色（#0D9488）为主旋律，融入微透毛玻璃（Glassmorphism）与微发光渐变粒子，营造充满生机与求索活力的当代东方视觉。
- **异形朝代轮廓体系（拒绝呆板矩形）**：
  - **唐代海棠/菱花形**：用于诗人头像、印章、成就勋章等；
  - **宋瓷葵口/花瓣形**：用于诗词拼组选项按键、操作卡片；
  - **飞檐弧与月洞门**：用于底部时间轴托盘、人生岔路弹窗顶部流线。
- **地图**：极简现代山水矢量风，碧翠江流、晨雾山岳与微光印记。
- **诗词场景**：现代大气的高清意境山水 + 书法与现代排版结合 + 春日微光粒子。
