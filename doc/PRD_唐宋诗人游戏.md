# 唐宋诗人沉浸式体验游戏 — 产品需求文档（PRD）

**版本**：v1.0 · **日期**：2026-06-25 · **状态**：草稿

---

## 一、项目概述

本游戏以互动叙事为核心，让玩家代入唐宋著名诗人的视角，跟随其在真实历史路线上游历，在正确的时间与地点见证并参与著名诗词的创作过程，同时探索诗人之间的关系网络。

游戏的根本差异在于**"玩法驱动教育"**而非"内容展示教育"：玩家通过管理情绪资源、做出人生选择、参与诗词拼组、维护诗人关系，在主动的游戏行为中自然习得诗词内容与历史背景，而非被动观看。

---

## 二、产品定位

### 2.1 游戏类型

**互动叙事冒险 × 教育科普（Educational Interactive Narrative）**

参考作品：《80 Days》（旅程资源管理）·《Pentiment》（历史沉浸叙事）·《Florence》（情感驱动交互）

### 2.2 核心价值对比

| 维度 | 传统教育产品 | 本游戏 |
|------|-------------|--------|
| 学习方式 | 被动阅读 / 观看 | 主动选择与参与 |
| 诗词呈现 | 课文 + 注释 | 创作场景还原 + 拼词参与 |
| 历史感知 | 时间线知识点 | 地图游历 + 时代洪流事件 |
| 人物关系 | 文字描述 | 可互动的唱和与关系图谱 |
| 成就感 | 考试成绩 | 典藏收集 + 结局解锁 |

## 三、目标用户

### 3.1 主要用户群（12–25 岁）

- **中学生**：语文课外延伸，以趣味方式深化对诗词背景与意境的理解
- **大学生**：文化爱好者，希望通过游戏方式系统接触古典文学
- **教育场景**：可作为课堂辅助工具或自主学习材料

### 3.2 次要用户群（25–40 岁）

- **文化爱好者**：喜欢历史与文学，希望以新形式重温古典诗词
- **家长群体**：为子女寻找兼具娱乐与教育价值的内容产品

### 3.3 设备与使用场景

| 场景 | 设备 | 预期单次时长 |
|------|------|-------------|
| 课外自学 | PC / 平板 | 20–40 分钟 |
| 课堂辅助 | 教室大屏 / 平板 | 15–20 分钟 |
| 休闲娱乐 | PC / 平板 | 30–60 分钟 |

## 四、功能需求

按优先级分为三级：**P0** 为 MVP 必须完成，**P1** 为第二期目标，**P2** 为长期规划。

### 4.1 P0 — 必须有（MVP 范围）

| 功能模块 | 描述 | 验收标准 |
|---------|------|---------|
| 地图系统 | 可交互的唐朝地图，含历史地名与诗人游历路线 | 10 个地点可点击，路线动态绘制 |
| 时间轴系统 | 横向时间轴，显示关键事件与诗词节点 | 各类事件点可点击展示简介 |
| 情绪驱动系统 | 5 维情绪值，事件与地点改变情绪，影响诗词触发 | 情绪条实时更新，阈值满足自动触发 |
| 诗词触发场景 | 水墨风格沉浸场景 + 背景旁白 + 诗词呈现 | 10 首诗词场景均可触发 |
| 诗词拼组 | 关键词填空 + 即时反馈 + 错选教学说明 | 每首诗 1–3 处填空，错误有逐项解释 |
| 典藏系统 | 已解锁诗词的收藏与全文赏析界面 | 进度展示 + 场景与背景可回看 |
| 李白主线 | 李白完整一生（10 首诗词，15 个事件） | 完整体验可在 1–2 小时内完成 |

### 4.2 P1 — 应该有（第二期）

- 人生岔路系统：历史节点选择 + 历史真相揭示
- 唱和交流系统：诗人互发诗词 + 关系值管理
- 人物关系图谱：基于 D3.js 的可交互网络可视化
- 杜甫完整主线：含与李白关系线激活
- 时代洪流完整版：历史大事件重塑地图与情绪

### 4.3 P2 — 可以有（长期规划）

- 更多诗人：王维（唐）、苏轼、李清照、辛弃疾（宋）
- 宋朝地图：独立宋代历史地图，与唐代可切换
- 音效系统：古典乐器配乐、场景环境音效
- 移动端适配：iOS / Android 响应式或原生 App

## 六、技术平台要求

| 要求项 | 规格说明 |
|--------|---------|
| 目标平台 | Web 端（PC 优先，支持平板） |
| 浏览器支持 | Chrome 90+ / Safari 14+ / Firefox 88+ |
| 最小视口宽度 | 1024px（桌面端） |
| 首屏加载时间 | ≤ 5 秒（宽带）；≤ 10 秒（3G 网络） |
| 地图交互响应 | ≤ 100ms |
| 用户账号 | 无需注册即可游玩；注册后跨设备同步进度 |
| 本地存储 | LocalStorage（访客）；云端 API（注册用户） |
| 无障碍 | 键盘可操作核心功能；主要图像含 Alt 文字 |

## 七、成功指标

| 指标 | 目标值 | 测量方式 |
|------|--------|---------|
| 单次游戏时长 | ≥ 15 分钟 | 埋点统计平均会话时长 |
| 诗词解锁完成率（共 10 首） | ≥ 60% | 统计触发 ≥ 6 首的用户占比 |
| 拼词首次正确率 | 40%–70% | 统计首次选择正确的比率（太高=太易，太低=太难） |
| 次日留存率 | ≥ 30% | 次日回访用户比例 |
| 教育效果（抽样） | 诗词背景回忆提升 ≥ 30% | 游戏前后问卷对比（抽样 50 人） |
| 用户满意度 NPS | ≥ 40 | 游戏结束后问卷 |
