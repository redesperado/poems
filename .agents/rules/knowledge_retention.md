# 关键知识留存与文档持续更新规则 (Knowledge Retention Rule)

## 规则目标
确保本项目所有关键信息（包括但不限于：UI/UX 设计成果、Google Stitch 提示词迭代、游戏系统设计变更、移动端 APP 兼容配置、技术架构决策）都能及时归档并持续更新到 `Context.md` 与 `doc/` 目录下的文档中，保证在上下文压缩、会话重置后历史决策不丢失、不偏离。

## 执行准则
1. **优先查阅 Context.md**：在每次执行新任务或跨会话启动时，必须快速浏览根目录下的 `Context.md`，同步最新的项目定位、设计规范与决策记忆。
2. **常驻记忆同步更新**：每当做出核心架构变动、技术选型或重大设计调整时，必须同步简明更新 `Context.md` 及底部“决策日志”表格。
3. **即时留存到 doc/**：产出新的界面设计提示词、新增页面模块或扩展系统规格时，同步更新对应的深度文档（如 `doc/UI设计提示词与原型指南_Stitch.md`、`doc/GDD_唐宋诗人游戏.md` 等）。
4. **记录更新日志**：在文档底部的“更新日志与留存记录”表格中追加更新版本、日期和修改摘要。
5. **保持中英双语可复制性**：对于涉及外部 AI 工具（如 Stitch、Midjourney 等）的提示词，保持清晰的英文 Prompt 块，便于用户一键复制使用。
