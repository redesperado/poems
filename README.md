# 唐宋诗人沉浸式游历游戏 (Tang-Song Poetry Game)

> **“玩法驱动教育”** —— 互动叙事冒险 × 古典诗词科普  
> 基于真实历史地图与年代轨迹，以诗人视角亲历名篇创作全过程。

---

## 📖 项目简介

本项目以唐宋历史为舞台，让玩家化身为李白等著名诗人，漫步于盛唐山河之间。通过**5维情绪资源管理**、**人生历史抉择**、**沉浸式诗词填空推敲**与**文人社交网络**，在探索与决策中自然领悟古典文学名篇的创作心境与时代意象。

* **核心设计定位**：参考《80 Days》《Pentiment》《Florence》等叙事设计，颠覆传统死板说教，提供兼具人文厚度与当代审美的交互体验。
* **视觉美学**：**「新东方·春生」（Neo-Oriental Spring）** —— 告别泛黄老旧水墨，拥抱晨露冷白与春水新绿，融入唐代海棠形、宋瓷葵口、飞檐弧线等朝代异形轮廓系统与现代毛玻璃质感。

---

## 🔄 核心游戏循环 (Gameplay Loop)

```
   [做出选择] ──> [游历地图] ──> [情绪积累]
        ↑                              │
        │                              ▼
   [揭秘收藏] <── [拼词创作] <── [诗词触发]
```

1. **做出选择**：在行进路线、书信往来、重大历史节点做出决策；
2. **游历地图**：动态行进于历史真实路线，触发沿途风土与历史事件；
3. **情绪积累**：5维情绪动态变化（豪情、忧思、洒脱、愤懑、乡愁），月度自然衰减；
4. **诗词触发**：当时间、地点与心境条件契合时，激发灵感涟漪；
5. **拼词创作**：四选一精准填空，含逐项深度文学赏析与无阻断跳过机制；
6. **揭秘收藏**：诗词与名场面入库典藏阁，解锁生平轶事与时间轴节点。

## 🎨 视觉与交互规范

* **主色调**：晨露冷白 (`#F6F9F5`)、春水碧 (`#10B981`)、晴空青瓷 (`#0D9488`)、春阳暖金 (`#F59E0B`)、桃夭粉 (`#F472B6`)、曜岩墨 (`#0F172A`)
* **朝代异形轮廓**：
  * **唐代海棠形/菱花弧**：用于诗人头像、成就勋章；
  * **宋代葵口/花瓣折沿**：用于诗词选项按键；
  * **飞檐弧与月洞门**：用于底部时间轴托盘与弹窗底座。
* **移动端兼容**：适配 `100dvh`，点击热区 $\ge 44\text{pt}$，零 Hover 依赖，支持未来一键打包为 iOS / Android 原生 App。
